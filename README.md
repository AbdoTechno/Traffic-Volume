# Traffic Volume

This project downloads the Metro Interstate Traffic Volume dataset from the UCI Machine Learning Repository and saves it locally as a CSV file.

## Contents
- `fetch_data.ipynb` — notebook that fetches the dataset and exports it
- `traffic_volume.csv` — saved dataset file generated by the notebook

## How to run
1. Open the notebook in Jupyter or VS Code.
2. Run all cells.
3. The dataset will be saved in the same project folder as `traffic_volume.csv`.

## Dataset source
- UCI Machine Learning Repository
- Dataset: Metro Interstate Traffic Volume
- Link: https://archive.ics.uci.edu/dataset/492/metro+interstate+traffic+volume

## Notes
- The exported file is generated using pandas.
- It is saved without the index column.
