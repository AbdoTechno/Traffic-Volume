# Traffic Volume Analysis

This project analyzes the Metro Interstate Traffic Volume dataset from the UCI Machine Learning Repository. The goal is to study traffic patterns, identify the main factors affecting traffic volume, and prepare the dataset for modeling and evaluation.

## Project structure
- notebooks/01_data_collection.ipynb — notebook for downloading and exporting the raw dataset
- notebooks/02_traffic_analysis.ipynb — main analysis notebook for EDA and modeling preparation
- data/raw/ — original downloaded dataset files
- data/processed/traffic_volume.csv — cleaned and processed dataset ready for use
- src/ — source scripts if needed later
- docs/ — project documentation
- reports/ — final reports and presentation files

## Data source
- UCI Machine Learning Repository
- Dataset: Metro Interstate Traffic Volume
- Link: https://archive.ics.uci.edu/dataset/492/metro+interstate+traffic+volume

## How to run
1. Open the notebook in the notebooks folder.
2. Run the data collection notebook first if you need to fetch the raw data again.
3. Use the analysis notebook to load the dataset from the data folder and start the exploration.

## Notes
- The processed dataset is saved in the data/processed folder.
- The notebook is organized to support team work and project reporting.
