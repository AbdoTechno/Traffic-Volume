# 02 - Data Cleaning

## اسم الطالب/ة:

## المهمة
شرح خطوات تنظيف البيانات ومعالجتها قبل النمذجة.

## المطلوب
- التعامل مع القيم المفقودة
- إزالة القيم المكررة
- تصحيح القيم غير المتسقة
- التحقق من أنواع البيانات
- أي عمليات تنظيف أخرى تم تطبيقها

## نموذج لكتابة النتائج
- تم فحص البيانات للتأكد من وجود القيم المفقودة.
- تم التعامل مع القيم الناقصة باستخدام ...
- تم حذف السجلات المكررة إن وجدت.
- تم تحويل أنواع البيانات إلى الشكل المناسب للنمذجة.

## ملاحظات
- اكتب الخطوات بالتفصيل
- أضف أمثلة إن لزم الأمر
- اذكر إذا كنت قد أضفت متغيرات جديدة
