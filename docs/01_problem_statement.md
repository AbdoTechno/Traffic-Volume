# 01 - Problem Statement

## اسم الطالب/ة:

## المهمة
اكتب مقدمة مختصرة عن المشروع، ووضح المشكلة الأساسية التي يحاول المشروع حلها.

## المطلوب
- شرح المشروع بشكل عام
- تحديد المشكلة أو السؤال البحثي
- لماذا هذا الموضوع مهم؟
- ماذا نريد أن نتنبأ أو نحلله؟

## مثال نص
This project aims to analyze traffic volume patterns using the Metro Interstate Traffic Volume dataset. The main objective is to understand the factors that influence traffic flow and build a model that can predict traffic volume more accurately.
