# 03 - Exploratory Data Analysis (EDA)

## اسم الطالب/ة:

## المهمة
عمل تحليل استكشافي للبيانات وتفسير النتائج.

## المطلوب
- إحصائيات وصفية
- المتوسط، الوسيط، الانحراف المعياري
- القيم الدنيا والعظمى
- تحليل العلاقات بين المتغيرات
- الرسوم البيانية إن توفرت

## أمثلة للنتائج
- أعلى حركة مرور تحدث خلال ساعات ...
- هناك علاقة بين الطقس وحجم المرور
- حركة المرور تكون أعلى خلال ...

## ملاحظات
- أضف الرسوم البيانية إن أمكن
- اشرح ما الذي لاحظته في البيانات
- اكتبInsight واضح ومباشر
